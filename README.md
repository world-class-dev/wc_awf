# WC_AWF (Autonomous Web Assembly Framework)

Autonomous Cross-Platform Native Engine written in Pure Rust for WebAssembly, Android NDK, iOS Metal, and Desktop targets.

## Features
- **Zero HTML DOM Overhead**: Direct WebGL/Canvas2D & Native Hardware Surface Rendering.
- **Cross-Platform**: Targets WebAssembly (`wasm32-unknown-unknown`), Android (`ANativeWindow`), iOS (`Metal`), and Desktop (X11/Wayland/Win32).
- **Hardened Sandboxing**: Custom linear memory allocator & e2pass encrypted pipeline bridge.
- **No Heavy GUI Dependencies**: Pure Rust vector rasterization and input event loop.
